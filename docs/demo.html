Quick Start

No Kaggle credentials or local training required. One command brings up the full stack.

Option A — Docker (recommended)

  1. Clone the repo:
    git clone https://github.com/sampathshetty85/cats-dogs-mlops
  2. Enter the directory:
    cd cats-dogs-mlops
  3. Start the full stack:
    docker compose up -d
  4. Wait ~30s for the API to become healthy, then open this page

Option B — Local Python

  1. Create venv:
    python3 -m venv .venv && source .venv/bin/activate
  2. Install dependencies:
    pip install -r requirements.txt
  3. Start API:
    uvicorn src.api.main:app --reload
  4. Open this demo page
# Full stack (API + Prometheus + Grafana)
