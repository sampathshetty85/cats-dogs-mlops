CI/CD

Every push to main triggers the CI workflow: lint (flake8) → unit tests (7 tests) → Docker build (multi-arch) → push to ghcr.io. On a successful push, the CD workflow pulls the new image, starts the stack, and runs the smoke test against /health and /predict.
